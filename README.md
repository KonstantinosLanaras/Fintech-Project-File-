This repository contains all the FinTech projects I undertook during my time at Politecnico di Milano.
The goal of the repository is to inform the reader about my experience with different technological tools relevant to the FinTech sector in which I aspire to enter. Languages covered are Python, R, and Solidity, with which I was able to provide analysis on financial problems through data-driven approaches leveraging the aforementioned technologies. Notably, the topics tackled were: Credit Approval Algorithm, Time Series Securities Analysis, Value at Risk, and Portfolio Optimization. Under every folder, the reader can find the resources (data), the source code, and a brief description of the project goals and significant findings.
